Defend Object Detectors Against Adversarial Attacks

A black-box defense boundary featuring vectorized frequency-domain anomaly detection, multi-view consistency verification, and fail-safe abstention.

Defense Architecture

● Vectorized 2D DCT Anomaly

Precomputed 8×8 DCT basis tensor multiplication identifies high-frequency energy spikes typical of adversarial patches in under 7 ms.

● Multi-View Consistency

Generates spatial and photometric transformations (denoising, median filter, recompression) and measures detection agreement across views.

● Patch Inpainting & Recovery

Suspicious regions detected by anomaly heuristics are masked and inpainted with Navier-Stokes reconstruction to restore obliterated objects.

Quickstart

Clone and run automated tests locally:

git clone https://github.com/rroshinii/Argus_shield.git
cd Argus_shield
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements-lock.txt
pytest -v

Start the FastAPI service and desktop UI:

# Start API Gateway
python -m uvicorn api.main:app --port 8000

# Run native desktop instrument panel
python -m ui.desktop
